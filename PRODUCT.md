# Product

## Register

product

## Users

HyperGen serves video creators, researchers, and developers who want one desktop workflow for local LTX generation and hosted text-to-video APIs. They work in generation, asset review, and editing flows where provider setup should stay out of the way once configured.

## Product Purpose

HyperGen is an open desktop workspace for generating and managing video across local models, curated API providers, and compatible self-hosted endpoints. Success means a user can install the app, choose a viable local or hosted path, generate a video, and understand the job state without learning provider-specific infrastructure.

## Brand Personality

Precise, capable, and direct. The supplied outlined H mark is the primary product signature. Product copy should be calm and concrete, with technical provider and model names presented accurately.

## Anti-references

Avoid decorative AI-tool clichés, provider-branded authentication gates, promotional copy inside work surfaces, excessive motion, and visual changes that make familiar controls harder to recognize. HyperGen should not obscure upstream licenses or rename technical LTX models.

## Design Principles

1. Keep the creation task in focus; configuration appears only when it is needed.
2. Use one consistent identity across startup, desktop, remote, settings, installers, and release metadata.
3. Reveal capability differences before submission so unsupported or billable requests are prevented.
4. Preserve familiar component behavior and established information density.
5. Make local, hosted, and self-hosted choices understandable in plain language.

## Accessibility & Inclusion

Target WCAG 2.1 AA contrast and keyboard access. Respect reduced-motion preferences, never rely on color alone for state, and keep status and error text readable in both light and dark themes.
